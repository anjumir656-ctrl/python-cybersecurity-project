# Python Cybersecurity Project

A beginner-friendly cybersecurity project built with Python.

## 🔐 Password Strength Checker

This project checks the strength of a password based on common security criteria.

### Features

- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Displays the password strength as Weak, Medium, or Strong

## 🛠️ Technologies Used

- Python
- Basic Cybersecurity Concepts
- String Handling
- Conditional Statements

## 🎯 Purpose

This project was created to practice Python programming and understand basic password security concepts.

## ⚠️ Disclaimer

This project is for educational purposes only. It does not store or transmit passwords.
